# How-to-setup-a-Linux-Environment-on-Android

A short article explaining how to employ a fully functional Linux desktop on an Android device.

# DEVICE

First of all,  it is HIGHLY recommended to use an adapter for your device to allow the use of a keyboard.  

A tablet with both a keyboard and mouse would be optimal here but this setup will work with any device running Android 8+.

# APP CHOICE

Our two main choices of apps to run our terminal are: 
### UserLAnd 
(no thats not a typo) which comes with gui out of the box as well as, many different distros of Linux to choose from.

I have ran into issues installing specific dependencies while programming though i.e. SDL & openGL.


### Termux 
which is just a terminal emulator with no gui. Yet much more packages ready to use.

The setup is longer but Termux is the superior option here.

# DEPENDENCIES

Very simple here just open the Play store and download:

### Termux
The physical terminal emulator.

### Termux:X11 
The app used to display our gui.

### Termux:Styling(optional)
Used to change color and font of the terminal.  Will require FDroid APK Installer for free version.
